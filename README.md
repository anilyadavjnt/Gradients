# 🎨 Gradients

A beautiful and simple iOS application built using **Swift + UIKit**, showcasing modern color gradients with a clean and minimal user interface.

## ✨ Features

- 🎨 Beautiful gradient backgrounds
- 🌈 Smooth color blending
- 📱 Clean and modern UI
- ⚡ Built with Swift
- 🧩 UIKit-based implementation
- 📐 Responsive iOS layout

## 🛠️ Technologies Used

- Swift
- UIKit
- Xcode
- CAGradientLayer
